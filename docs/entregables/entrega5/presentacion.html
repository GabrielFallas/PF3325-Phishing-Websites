Datos

Dataset UCI Phishing Websites

  • 11 055 instancias etiquetadas
  • 30 features en 4 categorías
  • Codificación ternaria: +1 legítimo, 0 sospechoso, −1 phishing
  • Clases balanceadas: 55.7% legítimo / 44.3% phishing

Categorías

Address Bar (12)Abnormal (6) HTML/JS (5)Domain (7)

Ejemplos de features

having_IP_Address · URL_Length · SSLfinal_State · URL_of_Anchor · age_of_domain · DNSRecord

El valor 0 (sospechoso) aporta información que un flag binario perdería → no se binariza.

Implementación

Arquitectura del sistema

Una rama offline entrena y persiste; una rama en tiempo real reutiliza el modelo para clasificar URLs nuevas.

Implementación · Modelo

Red neuronal MLP

128→64→32→1 · BatchNorm + Dropout + L2 + Early Stopping · 15 105 parámetros

Implementación · Detección en tiempo real

Extractor de features desde una URL

Medido en vivo (24/30)

  • URL: IP, longitud, acortadores, @, subdominios (tldextract)
  • Transporte: handshake TLS real, conteo de redirects
  • HTML/JS: anchors/links externos, SFH, iframe, pop-ups (BeautifulSoup)
  • Red: registros DNS, edad de dominio vía WHOIS

Honestidad: 6/30 con default

Dependen de servicios descontinuados:

  • web_traffic → Alexa (cerrado 2022)
  • Page_Rank → Toolbar PageRank (2016)
  • Links_pointing, Google_Index, Statistical_report

Cada feature reporta su procedencia (measured / default).

Discusión

Limitaciones (honestas)

  • Antigüedad del dataset (2014): las tácticas de phishing evolucionaron; las métricas absolutas pueden sobreestimar el desempeño actual.
  • Shift de distribución: features cuyas fuentes (Alexa, PageRank) ya no existen → se usan defaults. La procedencia lo hace explícito.
  • Extracción de contenido: requiere descargar la página → latencia y defensas anti-scraping.

Trabajo futuro

  • Reentrenar con dataset moderno de features 100% reproducibles online (léxicas de URL).
  • Caché y batching asíncrono en la API; confianza calibrada que marque veredictos de baja evidencia.

Conclusión

Construimos un sistema end-to-end: un MLP regularizado con 96.5% accuracy y 98.8% recall, más un servicio de detección en tiempo real (extractor + API + demo) — el componente desplegable ausente en los trabajos fundacionales.
